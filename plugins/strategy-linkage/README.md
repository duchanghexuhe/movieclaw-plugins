# 策略联动（`strategy-linkage`）

按明确配置的条件评估 MovieClaw 任务，并执行对应动作。

## 规则逻辑

- 单条规则内：所有已配置条件均须满足（AND）。
- 多条启用规则之间：任意一条满足即可触发（OR）；同一任务按规则顺序处理。
- 未配置的条件不参与判断。新规则不会默认勾选事件。
- 默认开启模拟模式；先检查命中结果，再关闭模拟模式执行真实动作。

## 可用条件

- PT 站点、下载器、资源类别、下载来源。
- 已采集事件、事件发生后的经过时间、每日定时。
- 下载器任务状态、完成度、累计上传量、当前上传/下载速度、分享率、资源大小、可验证的 H&R 状态。

## 可用动作

- 发送策略联动通知。
- 从下载器移除任务并保留本地文件，或移除任务并删除本地数据文件。
- 设置/取消下载器全局上传与下载限速。
- 启用/关闭备用限速模式和下载队列管理；设置最大同时下载数/做种数。
- 为 MovieClaw 投递且当前停滞的订阅任务请求换源；该动作要求规则明确限定来源为“订阅”、状态为“停滞”。

全局限速、备用限速和队列动作会影响所选下载器中的其他任务，不是单个种子的设置。

## 数据来源与限制

插件通过 MovieClaw 公开的宿主操作和事件工作，不直接连接 qBittorrent / Transmission，也不管理下载器凭据。任务评估范围以宿主 `dl.tasks` 返回的当前任务为准；任务中心未返回的历史种子无法评估。当前公开接口不支持单种限速、暂停/恢复、优先级、可靠的实际做种时长或站点剩余保种期限，因此这些不作为可用条件或动作。

移除任务前会通过宿主预演检查目标。明确返回任务不存在时记录为“未命中”；无法确认目标是否存在或其他安全校验不通过时不会执行动作。

## 安装

插件发布到市场后，可在 MovieClaw「设置 → 插件 → 插件市场」安装；也可在「设置 → 插件 → 已安装」上传 `.mcplugin`。安装时按提示批准插件页面及所申请的宿主操作权限。首次使用建议保持模拟模式，确认条件和动作无误后再启用真实执行。
